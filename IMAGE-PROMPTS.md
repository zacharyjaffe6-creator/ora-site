# Featured Timepieces — copy-paste image prompts

Eight self-contained prompts. Copy one block, paste, generate. Nothing to
assemble.

**Save to:** `public/products/01.webp` … `08.webp` (placeholders are in there
now — just overwrite them, same filenames).
**Output:** 1200 × 1500, WebP quality 80–85.

> Naming a real watch and reference number in front of the prompt will lock a
> design in faster, but what comes back is that manufacturer's product and is
> not yours to publish. The prompts below are written to stand on their own and
> to avoid garbled fake logos; keep the house you are building for fictional.

## Fixes if a render drifts

Append to the prompt that misbehaved:

| Problem | Append |
| --- | --- |
| Watch too small in frame | `tight crop, watch fills 80 percent of frame height` |
| Grey or gradient background | `pure flat solid #0A0D14 background, no gradient, no backdrop, no floor` |
| Garbled fake logo on the dial | `completely blank dial text, no lettering anywhere` |
| Wrist or model appears | `product only, isolated object, no model, no wrist, no hand, no skin` |
| Heavy drop shadow baked in | `no shadow, no contact shadow, floating on flat background` |
| Too warm / yellow | `neutral white balance, 5600K, no warm cast` |

## Keeping the set coherent

Generate all eight in one session with the same model and seed family. The rail
puts four on screen at once, so a lighting mismatch between neighbours is
obvious. If one is off, regenerate *that one* against the same prompt rather
than rewriting the style.

## Swapping in different products

Edit the `PRODUCTS` array at the top of
`src/components/FeaturedTimepieces.jsx`. Each entry takes `image`, `brand`,
`model`, `ref`, `price`, `status`, and `tone` (`ok` green · `warn` amber ·
`mute` grey).
